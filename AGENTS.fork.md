# Rules for agents in this repo (our pipeline)

This repo is a **reference mirror** of someone else's project, Parked in the owner's pipeline. We do not build features here. The daily fork sync merges upstream into it; anything else needs the owner's word first.

- Stage and reason: `PIPELINE.md`. History of our changes: `CHANGELOG.fork.md`.
- Upstream owns everything else in this repo (README, code, docs): never rewrite their files, or every sync conflicts.
- No private details in code, commits or PR text: no names, e-mail addresses, home paths or machine names. Commit as the no-reply identity.
